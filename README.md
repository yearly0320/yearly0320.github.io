# 烨的个人小站

这是 yearly0320 的 GitHub Pages 个人网页项目，用于展示个人主页、散文、少年日记、游戏和音乐等内容。

## 访问网址

网页地址：

```text
https://yearly0320.github.io
```

在浏览器中打开上面的网址即可进入个人网页。

## 页面说明

- **`index.html`**
  - 网站首页。
  - 展示头像、欢迎语、个人介绍、导航入口和底部访问统计。

- **`prose.html`**
  - 散文页面。
  - 用于展示散文、随笔和文字内容。

- **`diary.html`**
  - 少年日记入口页。
  - 按年份和月份展示日记索引。

- **`diary/201701.html`**
  - 2017 年 1 月日记详情入口。
  - 用日历形式展示当月日记。

- **`game.html`**
  - 游戏页面。
  - 用于记录或推荐喜欢的游戏。

- **`music.html`**
  - 音乐页面。
  - 用于记录或推荐喜欢的音乐。

## 浏览统计说明

页面底部包含本地浏览统计：

- **本设备访客**：当前浏览器是否访问过本站。
- **本设备总浏览**：当前浏览器访问本站页面的累计次数。
- **本设备本页浏览**：当前浏览器访问当前页面的累计次数。

这些统计数据保存在浏览器本地 `localStorage` 中。不同电脑、不同浏览器、清除浏览器数据后，数字会重新开始。

## 本地预览

进入项目目录后，可以使用 Python 启动本地预览：

```bash
python3 -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

## 修改并发布

修改网页文件后，使用 Git 提交并推送到 GitHub：

```bash
git status
git add .
git commit -m "Update personal website"
git push
```

推送成功后，GitHub Pages 通常会在几十秒到几分钟内自动更新网站。
